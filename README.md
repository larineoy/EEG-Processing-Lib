## Overview

The **EEG-Processing-Lib** is a Python-based toolkit designed to facilitate the preprocessing and analysis of EEG data. It currently focuses on plotting the EEG data.

## Installation

To install the EEG Processing Library, clone this repository and install the required dependencies:

```bash
git clone https://github.com/larineoy/EEG-Processing-Lib.git
cd EEG-Processing-Lib
pip install -r requirements.txt
